# AI-Powered Travel Claim Assistant (ril.claim.assistant)

An automated, enterprise-ready expense tracking and compliance auditing engine built in Python. Powered by the **Gemini 3.8-Flash architecture**, this workspace extracts and compiles unstructured business travel receipts into standardized CSV datasets ready for ERP ingestion.

## Architecture
- `claim_assistant_main.ipynb`: Core engineering laboratory & iteration history.
- `User_Main.ipynb`: Minimalist single-cell end-user dashboard.
- `/Documentation/`: Archived development logs and build iteration notes.
